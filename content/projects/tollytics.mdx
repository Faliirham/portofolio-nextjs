Tollytics is a comprehensive big data solution built to monitor, analyze, and optimize toll road operations. By combining real-time IoT data streams with Hadoop for massive data processing, the system provides actionable intelligence.

## Contributions

- Developed Software System with Next.js and Node.js
- Integrated IoT real-time data
- Implemented Hadoop for big data processing
- Designed scalable cloud architecture

## Impact

Enabled real-time monitoring and analytics of toll operations, significantly improving decision-making speed and infrastructure management.
