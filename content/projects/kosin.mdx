Kosin is a full-stack web platform for discovering boarding houses (kos-kosan). It pulls boarding house data from OpenStreetMap via the Overpass API, stores it in PostgreSQL, and presents it through an interactive dashboard with a live map — making the search for a place to stay data-driven and visual.

## Contributions

- Built interactive map dashboard with Vue
- Implemented Overpass API data ingestion from OpenStreetMap
- Designed PostgreSQL schema for geospatial data
- Developed backend data processing pipelines with Python

## Impact

In development — aims to make boarding house discovery data-driven by leveraging open geospatial data.
